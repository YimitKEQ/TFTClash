BrosephTech Bot

Voice meetings to tasks · accountability board · live command center

Talk in a voice channel and the bot writes your tasks. It records the call, transcribes it locally, summarizes it with AI, and turns the action items into board cards and Jira issues - then shows the whole operation on a live dashboard.

Record a meeting into tasks

The headline feature. /record start in a voice channel, talk, then /record stop.

  1. Join a voice channel and run /record start. The bot captures each person on their own track, so long calls never cut off after a pause.
  2. Talk normally. /record status shows who's been heard.
  3. Run /record stop (optionally title:Weekly sync). It transcribes locally on the GPU, then summarizes with Claude.
  4. Pick the real tasks from the checklist and hit Create selected. Each becomes a board card + a Jira issue, with the full transcript attached as a file.
Transcription runs locally with whisper.cpp - your audio never leaves the machine. Summaries + task extraction use the Claude API.

Slash commands

/record start · stop · status
Record the voice channel and turn it into suggested tasks. jiracheck verifies Jira.
/dashboard
Live command-center embed with a Refresh button (mirrors the web dashboard).
/metrics log · show
Log YouTube / TikTok / Patreon / avg-view numbers. Feeds the dashboard trends.
/meeting
Capture a meeting from pasted notes (the text version of /record).
/board · /mytasks · /scorecard
Board health, your own cards, and a crew member's accountability scorecard.
/card add · /blocked
Create a card; list everything blocked that still needs unblocking.
/standup · /digest
Post the standup snapshot or weekly digest right now.
/setup
Build the HQ category and its channels. Idempotent.

The dashboard

Open it at http://<host>:<port>/?k=YOUR_DASHBOARD_TOKEN (the token is saved to a cookie after the first visit). It auto-refreshes every 20 seconds. Add &demo=1 to preview with sample data.

KPIs, a "Do next" priority queue, a department donut, the board pipeline, per-crew load bars, the work that needs attention, a live Jira kanban board, and recent meetings + recordings - all in one place.
