Recap + Board + Jiracreated
  1. Join a voice channel, run /record start. Each person is recorded on their own track.
  2. Talk. /record status shows who's been heard.
  3. Run /record stop (optionally title:Weekly sync). You get a structured recap (TL;DR, decisions, blockers), a task checklist, and the transcript file.
  4. Tick the real tasks and hit Create selected. Each becomes a board card + Jira issue, and the full recap posts to #bt-meetings and the dashboard.
Transcription runs locally - audio never leaves the machine. Recaps use the Claude API.

Dashboard

Open in a browser:

http://<host>:<port>/?k=YOUR_TOKEN

Do next (what to act on now), Latest meeting recap, KPIs, department donut, board pipeline, per-crew load, work needing attention, a live Jira kanban, and meeting history. Read-only; auto-refreshes every 20s. Add &demo=1 to preview.

Setup (bt-bot/.env)

# AI summaries + tasks
ANTHROPIC_API_KEY=
# Local transcription
WHISPER_CMD= WHISPER_MODEL=
# Jira push
JIRA_BASE_URL= JIRA_EMAIL=
JIRA_API_TOKEN= JIRA_PROJECT_KEY=
# Web dashboard
DASHBOARD_TOKEN=

npm run deploy to register commands, then npm start. Restart after any .env change.
